### Q1

**質問：**
このコードはなにをしていますか
```Swift
ContentUnavailableView(
  "メモがありません",
  systemImage: "note.text",
  description: Text("右上の＋ボタンからメモを追加してください"
)
```

**AIの回答の要点：**
「空状態（Empty State）」のUIを表示するためのもの
Content​Unavailable​View は iOS 17 以降の SwiftUI に用意されている標準ビューで、
何も表示するコンテンツがない状況を、タイトル・アイコン・説明文つきで分かりやすく伝えるために使う。

**自分の理解：**
データがなかったら、ただ単にVStackやTextを使って表示すれば良いと思っていたが、
専用のものがあるのだと知り、これから使いたくなってみました。

### Q2

**質問：**
```Swift
Group {

}
.toolbar {}
```
のように使う.から始まるのをなんという？

**AIの回答の要点：**
SwiftUI の「モディファイア（modifier）」と呼ぶ。
View に対してドット記法で連鎖的に適用する拡張メソッドがモディファイア。
Group { ... }.toolbar { ... } のように、前のビュー（ここでは Group が返すビュー）に追加の振る舞いや見た目を付与
モディファイアは新しいビューを返す「純粋関数」的な設計で、元のビューを直接変更せず、修飾された新しいビューを合成します。
**自分の理解：**
今までなんとなく使っていたものの名称を改めて知ることができた。
